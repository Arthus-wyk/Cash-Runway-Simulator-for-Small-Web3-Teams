# Runway design

User-approved rules: USD income arrives before each monthly payment; cash then USDC then BTC/ETH sold proportionally by market value; B builds a one-time N × gross monthly expense cash reserve including existing cash, before the shock. Fee defaults to 0.1%, configurable. First shortfall ends a strategy; no extrapolation beyond 12 calendar months. Monthly dates clamp to month end and are strictly after the start date. UTC dates, day-close simulated execution. USDC has its own market price and shock.

Python 3.11+ standard library, Decimal engine, local threaded HTTP server, one native HTML/CSS/JS page. No dependencies, database, accounts, wallet or trading. Server is for local demo; public hosting requires a production server/reverse proxy. UI: input sidebar, scenario/reserve controls, payment count and first shortfall cards, daily mark-to-market curves, monthly ledger and JSON/CSV downloads. An illustrative team portfolio uses real CMC quotes; no fictional historical data. An explicit recorded-quote mode enables replay of the real evidence snapshot with its timestamp.

Price snapshot is pinned during slider changes, both strategies receive identical inputs and daily paths. Daily price = current quote × historical close / historical base close. B reserve fee is shown on day zero. Custom shock takes effect on day one. Daily total asset curves are marked-to-market, before hypothetical future liquidation fees. Monetary output rounded to cents, internal Decimal precision 40. No quantities rounded during calculation. Rounding residual below 1e-18 USD is zero, not a cent-sized solvency tolerance.

Basic access observed: map and latest 200, historical 403/1006. Three candidate 367-day historical windows remain unavailable until a manual authorized fetch succeeds for all three assets on every UTC date. Missing/duplicate/nonpositive historical prices reject a window; no interpolation. Basic stage is not full historical MVP completion.

Security: .env ignored; exact route allowlist prevents file exposure; trusted upstream hostname only; bounded body, numeric validation, same-origin POST, localhost bind. Server cache: latest 60s, refresh failure cooldown 60s, stale quote fallback only up to 24h and visibly marked. Immutable snapshots retained in bounded memory. Historical cache is local only; quota failures and permissions explicit. No secret values or upstream raw errors exposed to browser. Reports include inputs, quote dates, path, sources, fees, sale quantities and all rules.

Evidence: evidence/map.json, latest.json, historical.json record actual responses with redacted header, UTC capture time and HTTP status. Public repo, deployment, X publishing and final submission remain external handoff steps; no destination supplied.
